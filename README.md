# Myntra Clone

A React Native & Expo-based e-commerce mobile app that replicates Myntra's core shopping experience.

## Features

- Dark and Light mode toggle
- Browse categories, subcategories, and products
- Trending, Featured, and "You May Also Like" sections
- Add to Bag and Checkout with shipping & payment
- Order management with status updates
- Save items for later
- Local data storage using AsyncStorage

## Screens

1. Home Screen – Banner, Categories, Trending, Featured Products, Recently Viewed
2. Categories – Search, Filter by category & subcategory, View products
3. Product Details – View product info, Add to Bag, Save for later
4. Bag – View items, edit quantity, proceed to Checkout
5. Checkout – Enter shipping address & payment details
6. Orders – View order history, expand order details, cancel orders
7. Saved – View saved items, move to Bag
8. Settings – Toggle dark/light mode

## Tech Stack

- React Native
- Expo
- TypeScript
- AsyncStorage

## Installation

```bash
git clone https://github.com/your-username/myntra-clone.git
cd myntra-clone
npm install
expo start
````

## Notes

* All data is stored locally; no backend API required.
* Designed for learning and UI demonstration purposes.
* Supports both Android & iOS devices.
